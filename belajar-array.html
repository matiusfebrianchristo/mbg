Array List

Array ( larik ) adalah sekumpulan elemen berindeks, di mana setiap elemennya memiliki tipe data yang sama di dalam satu variabel tunggal. Tujuan penggunaan array adalah untuk menyederhanakan pengumpulan sebuah data. Seperti halnya rak sepatu, kita bisa mengisi rak tersebut dengan sebuah sepatu dan bisa mengambil sepatu tertentu berdasarkan posisinya. Adapun konsep array sebagai berikut:

  • • Tipe Data Seragam : semua yang tersimpan pada satu array harus memiliki tipe data yang sama. Misalkan berupa angka atau teks saja.
  • • Indeks: Indeks digunakan sebagai penanda posisi setiap data yang tersimpan di dalam sebuah array. Indeks ini selalu dimulai dari angka 0.
  • • Akses acak (random access) : Data dapat dibaca, diubah, dan dicari hanya dengan memanggil indeks dari data tersebut.

Misalkan kita memiliki sebuah array list yang berisi nama-nama buah. Contoh disini adalah "banana", "apple", dan "orange". Kita mencoba untuk membuat array dengan Bahasa pemrograman Python. Indeks array dimulai dari angka 0. Untuk mengambil data tertentu dalam sebuah array, kita bisa gunakan fungsi print() dalam python dengan memanggil variable array diikuti dengan indeks mana yang mau diambil.
Contoh : print(var_name[index])

Untuk mengambil seluruh data dalam array, kita perlu menggunakan perulangan untuk mengeluarkan data satu per satu. Kita dapat menambahkan, menghapus dan mengubah isi data pada array. Untuk menambahkan data menggunakan fungsi append() dan menginput data yang akan ditambahkan ke dalam parameter dan pop() untuk menghapus nilai di dalam list array.
