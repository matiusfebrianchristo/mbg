Struktur Data Majemuk

Array

Array ( larik ) adalah sekumpulan element berindeks, dimana setiap elemennya memiliki tipe data yang sama di dalam satu variabel tunggal. Tujuan penggunaan array adalah untuk menyederhanakan pengumpulan sebuah data.

Stack

Stack adalah struktur data yang menggunakan pengurutan LIFO (Last-In-First-Out) yang artinya element yang terakhir masuk akan menjadi elemen yang pertama keluar.

Array vs Stack

Fitur / Parameter Array Stack
Prinsip Kerja Akses Acak (Indeks) Last-In First-Out (LIFO)
